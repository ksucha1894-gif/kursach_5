# Проект: Атомные привычки (Бэкенд на Django REST Framework)

Приложение для трекинга и автоматизации полезных привычек с жесткой встроенной системой кибер-валидации бизнес-логики.

## Настройка локального бэкенда

1. Создайте базу данных в PostgreSQL:
   ```bash
   createdb atomic_habits
   ```
2. Разверните виртуальное окружение и установите зависимости через Poetry:
   ```bash
   poetry install
   ```
3. Активируйте виртуальную среду Poetry:
   ```bash
   poetry shell
   ```
4. Примените миграции для развертывания архитектуры:
   ```bash
   python manage.py migrate
   ```
5. Создайте суперпользователя (администратора):
   ```bash
   python manage.py createsuperuser
   ```
6. Запустите локальный сервер:
   ```bash
   python manage.py runserver
   ```

## Реализованная система валидаторов (Защита API)
- Запрет одновременного выбора вознаграждения и связанной приятной привычки.
- Ограничение времени выполнения привычки (не более 120 секунд).
- В связанные привычки могут попадать только привычки с флагом `is_pleasant=True`.
- У приятной привычки не может быть скрытых наград или других связанных действий.
- Контроль регулярности выполнения: не реже одного раза в 7 дней.

## Тестирование и покрытие кода (Coverage)

Для запуска интеграционных тестов и проверки покрытия бизнес-логики выполните следующие команды:

1. Запуск тестирования Django:
   ```bash
   poetry run python manage.py test
   ```
2. Сбор статистики покрытия утилитой coverage:
   ```bash
   poetry run coverage run --source='.' manage.py test
   ```
3. Вывод финального отчёта в консоль:
   ```bash
   poetry run coverage report
   ```
4. Запись результатов тестирования:
   ```bash
   poetry run coverage report > coverage.txt
   ```
